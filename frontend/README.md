# Frontend - Gym Analytics Management

## Requisitos

- Node.js 20+ (o 18+)
- Backend FastAPI corriendo en `http://127.0.0.1:8000`

## Configuración

1. Copia variables de entorno:

```bash
cp .env.example .env
```

2. Instala dependencias:

```bash
npm install
```

3. Ejecuta en desarrollo:

```bash
npm run dev
```

La app quedará disponible en `http://127.0.0.1:5173`.

## Build de producción

```bash
npm run build
npm run preview
```
